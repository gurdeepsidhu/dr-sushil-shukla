1. जरूरी चीजें (Things You Need)
================================================================================

आपको बस ये चीजें चाहिए:

✅ एक कंप्यूटर/लैपटॉप (Windows/Mac/Linux)
✅ Notepad या कोई भी text editor (Notepad, VS Code, Sublime Text)
✅ डॉक्टर की पूरी जानकारी (DOCTOR_DETAILS_FORM_HINDI.txt से भरी हुई)
✅ डॉक्टर की फोटोज (कम से कम 3-4 अच्छी फोटो)
✅ क्लिनिक की फोटोज (4-5 फोटो)
✅ इंटरनेट कनेक्शन (वेबसाइट publish करने के लिए)
✅ एक Gmail अकाउंट (GitHub पर signup के लिए)

कोई भी कोडिंग जानने की जरूरत नहीं है! बस कॉपी-पेस्ट करना आना चाहिए।

4. वेबसाइट फाइलों को समझना (Understanding Website Files)
================================================================================

ये सभी files हैं जो आपको मिलेंगी:

📄 index.html      — यह मेन वेबसाइट फाइल है। सबसे जरूरी।
                     इसमें ही सारी जानकारी बदलनी है।

📄 style.css       — वेबसाइट का डिज़ाइन (रंग, साइज, लेआउट)
                     इसमें ज्यादा बदलाव की जरूरत नहीं।
                     सिर्फ कलर बदलना हो तो यहाँ करें।

📄 script.js       — वेबसाइट के फंक्शन (BMI Calculator, Chatbot, etc.)
                     इसमें डॉक्टर का नाम और नंबर बदलना है।

📄 manifest.json   — मोबाइल ऐप जैसा बनाने के लिए
                     इसमें सिर्फ नाम बदलें।

📄 robots.txt      — Google को बताता है क्या index करना है
                     सिर्फ URL बदलें।

📄 sitemap.xml     — Google को सारे पेजेस की लिस्ट
                     सिर्फ URL बदलें।

📄 sw.js           — Service Worker (cache management)
                     इसमें कुछ नहीं बदलना।

📁 blogs/          — ब्लॉग पेज का फोल्डर
   └ index.html   — इसमें भी क्लिनिक का नाम बदलें।

📁 images/         — फोटोज रखने का फोल्डर (आपकी सभी फोटो यहाँ रखें)

5. प्लेसहोल्डर क्या हैं और कैसे बदलें (Placeholders & How to Replace)
================================================================================

इस टेम्पलेट में डॉ. गिल की सारी जानकारी की जगह {{PLACEHOLDER}} लगाए गए हैं।
आपको हर {{PLACEHOLDER}} को डॉक्टर की असली जानकारी से बदलना है।

उदाहरण:
❌ पुराना:  {{CLINIC_NAME}}
✅ नया:    Sharma Heart Clinic

❌ पुराना:  {{DOCTOR_FULL_NAME}}
✅ नया:    Dr. Rajesh Sharma

सबसे आसान तरीका — Find and Replace का use करें:

📌 METHOD 1: Notepad में Find & Replace
   1. index.html को Notepad में खोलें
   2. Ctrl+H दबाएं (Find and Replace)
   3. "Find what" में प्लेसहोल्डर डालें (जैसे: {{CLINIC_NAME}})
   4. "Replace with" में असली जानकारी डालें (जैसे: Sharma Heart Clinic)
   5. "Replace All" पर क्लिक करें
   6. हर एक प्लेसहोल्डर के लिए ऐसा करें

📌 METHOD 2: Visual Studio Code (FREE, ज्यादा आसान)
   1. https://code.visualstudio.com से Download करें
   2. index.html खोलें
   3. Ctrl+H दबाएं
   4. एक साथ सारे प्लेसहोल्डर find & replace कर सकते हैं

10. कलर बदलना (Changing Colors)
================================================================================

वेबसाइट का main color red (#d90429) है। अगर आप बदलना चाहते हैं:

style.css में line 6-7 पर:

:root {
  --primary: #d90429;       ← यह बदलें (जैसे: #0b5ed7 for blue)
  --primary-dark: #b50020;  ← यह भी उसी के हिसाब से
  ...
}

आम कलर कोड:
🔴 Red:    #d90429
🔵 Blue:   #0b5ed7
🟢 Green:  #16a34a
🟣 Purple: #7c3aed
🟠 Orange: #ea580c

प्रो टिप: style.css खोलें, Ctrl+H दबाएं,
"Find: #d90429" और "Replace: आपका नया कलर"

index.html (inline styles) में भी कलर #d90429 को बदलें!

13. फ्री में होस्ट करना — GitHub Pages
================================================================================

सबसे आसान और पूरी तरह FREE! 🎉

STEP 1: GitHub अकाउंट बनाएं
   1. https://github.com पर जाएं
   2. "Sign Up" करें (Gmail से आसानी से बन जाएगा)
   3. Username चुनें (जैसे: drsharma-web)

STEP 2: New Repository बनाएं
   1. Login करने के बाद "+" button → "New repository"
   2. Repository name: sharma-heart-clinic (या जो भी नाम रखना चाहें)
   3. "Public" चुनें
   4. "Create repository" पर क्लिक करें

STEP 3: Files Upload करें
   1. "uploading an existing file" लिंक पर क्लिक करें
   2. अपने कंप्यूटर से सारी files drag & drop करें:
      - index.html
      - style.css
      - script.js
      - manifest.json
      - robots.txt
      - sitemap.xml
      - sw.js
      - सभी .jpg फोटोज
      - blogs/ फोल्डर
   3. "Commit changes" पर क्लिक करें

STEP 4: GitHub Pages Enable करें
   1. Repository → "Settings" tab पर जाएं
   2. Left sidebar में "Pages" पर क्लिक करें
   3. "Branch" dropdown में "main" चुनें
   4. "Save" पर क्लिक करें
   5. 1-2 मिनट रुकें, फिर refresh करें
   6. आपको एक URL मिलेगा:
      https://drsharma-web.github.io/sharma-heart-clinic/

STEP 5: URL चेक करें
   - इस URL को खोलकर देखें — आपकी वेबसाइट live है! 🎉

अब यह URL आप किसी को भी WhatsApp/Message करके भेज सकते हैं।

15. आम समस्याएं और समाधान (Common Problems & Solutions)
================================================================================

❌ PROBLEM: फोटो नहीं दिख रही
✅ SOLUTION: चेक करें कि फोटो का नाम बिल्कुल सही है (hero.jpg, clinic1.jpg वगैरह)
             और फोटो उसी folder में है जहाँ index.html है।

❌ PROBLEM: मोबाइल में वेबसाइट टूटी हुई दिख रही है
✅ SOLUTION: यह responsive design है, ज्यादातर मोबाइल में सही दिखेगी।
             अगर कोई problem है तो style.css में जाकर mobile styles check करें।

❌ PROBLEM: WhatsApp बटन काम नहीं कर रहा
✅ SOLUTION: script.js में WhatsApp नंबर सही से बदला है क्या?
             नंबर में +91 नहीं, सिर्फ 91 लिखें (919876543210)

❌ PROBLEM: Google Map गलत जगह दिखा रहा है
✅ SOLUTION: index.html में map iframe का src बदलें।
             Google Maps खोलें → अपनी clinic ढूंढें → Share → Embed a map →
             URL कॉपी करें → index.html में iframe src में paste करें।

❌ PROBLEM: प्लेसहोल्डर ({{...}}) दिख रहे हैं
✅ SOLUTION: आप वो प्लेसहोल्डर replace करना भूल गए हैं।
             Ctrl+F से उस प्लेसहोल्डर को ढूंढें और असली जानकारी से बदलें।

❌ PROBLEM: Chatbot में पुराना नाम दिख रहा है
✅ SOLUTION: script.js और index.html (inline JS) दोनों जगह चेक करें।
             दोनों में chatbot replies हैं — दोनों जगह बदलें।

❌ PROBLEM: वेबसाइट बहुत धीमी लोड हो रही है
✅ SOLUTION: फोटोज का size कम करें (1MB से कम रखें)।
             https://tinypng.com पर जाकर compress करें।
